# Technology Stack

## Core
- **Framework**: Eleventy (11ty) static site generator
- **Templating**: Nunjucks (`.njk`)
- **Content**: Markdown (`.md`)
- **Scripting**: JavaScript (Node.js for build steps, Vanilla JS for client side)
- **Styling**: SCSS / CSS

## Deployment & Hosting
- **GitHub Pages**: `ultrainsync.github.io`
- **Cloudflare / WordPress**: `adsvise.me/on/` subfolder
- **CI/CD**: GitHub Actions
